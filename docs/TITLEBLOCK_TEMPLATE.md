# 企业 BOM 输出模板

在「系统设置 → 企业 BOM 输出模板」编辑。标题栏与明细使用同一套操作：选择范围，填输出名称，选取值来源，最后统一保存。

- **图纸标题栏**：每张图纸一份，输出到企业 JSON 的 `title_block`。可一键加入图名、图号、版本、图纸材料、比例、图纸标注重量和日期，也能加入设计、校核／审核、批准。首次未配置时，编辑器加载时就会填入常用预设，保存后才生效；加入预设不会覆盖已有字段。可设置多个来源，系统字段优先，同类来源按配置顺序取首个有效值；结果冲突时仍会提示复核。删除全部标题栏字段并保存，即停用标题栏输出。
- **零件明细**：每个零件一行，输出到企业 JSON 的 `rows`，或作为企业 CSV/Excel 列。可用系统明细字段、读取原图自定义列、引用同一模板的标题栏字段，或填写固定值／留空。
- 读不到的值在 JSON 中为 `null`，表格中留空。新增原图字段后需重新识别；离线 Mock 不会读取新字段。

两个范围的系统字段独立。比如「图纸材料」读标题栏，「零件材料」读每行明细，不互相补值。如果要给每个零件都带上整张图的图号，来源请选择「引用图纸标题栏」。

「导入、下载模板或载入示例」提供[统一 JSON 示例](../static/bom-output-template.example.json)。模板里的 `title_fields` 和 `bom_columns` 都由 `output`（输出名称）与 `sources`（取值来源）组成，无需手写 JSON。可读出已保存的旧版配置，也可导入 [旧标题栏 JSON](../static/titleblock-template.example.json) 或[旧企业配置](../examples/enterprise-profile.example.json) 到编辑区，只替换相应范围。同一页的审图规则与参数词典是独立可选项。

「下载当前模板」始终导出整个编辑区（包括还没保存的修改），当前打开的页签不会改变文件内容。若已停用标题栏，文件仍包括 `title_fields`，其值为 `[]`。

完整示例采用与当前模板下载相同的格式，包含常用标题栏预设和默认明细列，并额外演示「设计部门」「所属图纸图号」「涂层代号」「工厂代码」。这些示例值不是企业规则；导入后不需要的项可以删除。自定义明细来源的 `key` 是稳定的识别字段标识，修改显示名称时应保留它。

在正常配置模式下，两部分统一写入 `data/web_settings.json`，重启仍生效。历史 `data/titleblock_template.json` 在首次统一保存前继续作为备用读取来源。使用固定部署配置 `--config` 时，统一编辑器为只读。每次新 BOM 任务使用当时保存的模板；已有任务的标题栏识别结果不会被后续修改改写。

接口（使用 `X-API-Token`）：`GET /api/enterprise/bom-output-template` 读取模板与可选系统字段；`POST` 同一路径保存统一格式；`POST /api/enterprise/bom-output-template/preview` 校验并转换模板、但不写入配置。历史企业配置和标题栏 API 保留。
